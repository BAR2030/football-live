# فوتبال‌لایو — ربات تلگرام + نسخه وب Mini App

این پروژه یک سایت کوچک برای برنامه و نتایج مسابقات و یک ربات تلگرام دارد. ربات با `/start` دکمه بازکردن وب‌اپ را نشان می‌دهد. سایت مسابقات ۷ روز آینده را با روز، تاریخ و ساعت ایران از API دریافت می‌کند و هر ۶۰ ثانیه تازه‌سازی می‌شود.

## نکته درباره نتیجه زنده
در Football-data.org پلن رایگان، امتیازها با تأخیر هستند و پوشش آن به رقابت‌های مشخص محدود می‌شود. برای نتایج زنده واقعی/به‌روزتر ممکن است نیاز به طرح پولی یا ارائه‌دهنده دیگری باشد. این کد نتیجه‌ای را که API برگرداند نمایش می‌دهد؛ تضمین نمی‌کند داده در هر لحظه زنده باشد.
منبع: https://www.football-data.org/pricing و https://www.football-data.org/coverage

## فایل‌ها
- `index.html`: نسخه وب Mini App
- `server.py`: API واسط و ربات تلگرام؛ توکن فوتبال فقط سمت سرور می‌ماند
- `requirements.txt`: کتابخانه‌ها
- `.env.example`: تنظیمات
- `render.yaml`: نمونه تنظیم سرویس Render

## راه‌اندازی با Render (میزبانی وب و اجرای ربات)
1. در GitHub یک مخزن بساز و این فایل‌ها را بارگذاری کن.
2. در Render یک **Web Service** از مخزن بساز.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python server.py`
5. در Environment Variables این متغیرها را تعریف کن:
   - `BOT_TOKEN`: توکن رباتی که از `@BotFather` می‌گیری
   - `FOOTBALL_DATA_TOKEN`: API token از `https://www.football-data.org/`
   - `WEBAPP_URL`: بعد از انتشار، آدرس HTTPS سرویس Render، مثلاً `https://your-service.onrender.com`
6. پس از deploy، آدرس سایت را باز کن. در تلگرام به ربات `/start` بده تا دکمه وب‌اپ ظاهر شود.

**مهم:** اگر `WEBAPP_URL` را قبل از انتشار نداشته باشی، بعد از انتشار در تنظیمات Render اضافه‌اش کن و سرویس را redeploy کن. برای محیط عملیاتی بهتر است ربات polling در سرویس worker جدا اجرا شود؛ این نمونه برای شروع ساده است.

## تنظیم BotFather
وقتی سایت HTTPS بالا آمد:
- در `@BotFather` دستور `/setmenubutton` را اجرا کن، ربات را انتخاب کن، عنوان `⚽ فوتبال‌لایو` و URL سایت HTTPS را بده.
- همچنین دکمه `/start` خود ربات از طریق `WEBAPP_URL` وب‌اپ را باز می‌کند.

## تنظیم API
1. در `https://www.football-data.org/` ثبت‌نام و API token بگیر.
2. `FOOTBALL_DATA_TOKEN` را در تنظیمات محیطی سرویس قرار بده؛ هرگز آن را داخل `index.html` قرار نده.
3. رقابت‌های نمونه در `server.py` عبارت‌اند از PL, PD, BL1, SA, FL1, CL, DED, PPL. پوشش و مجوز هر رقابت به طرح API بستگی دارد. در پلن رایگان ممکن است تعداد درخواست‌ها محدود باشد.

## توسعه‌های بعدی

- پشتیبانی از لیگ‌های بیشتر با API مناسب
- صفحه جزئیات مسابقه و گل‌زنان
